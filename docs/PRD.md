# AI 产品调研 Agent 与 BI 决策平台 PRD

---

## 1. 产品概述

### 1.1 产品名称

AI Product Research Agent & BI Platform
AI 产品调研 Agent 与 BI 决策平台

### 1.2 产品定位

本项目是一个面向 AI 产品经理、数据产品经理和产品运营团队 AI Agent + BI 决策平台。

系统通过 Github Issues、用户评论、竞品资料和产品运行数据，采集真实用户反馈，并通过 LangGraph 编排多 Agent 工作流，完成用户痛点分析、竞品洞察、机会点评分、PRD草稿生成、AI 输出质量评估和 BI Dashboard 复盘。

本项目不是单纯的 AI 文档生成工具，而是一个围绕产品调研、产品决策、需求生成和效果评估构建的端到端产品工作流系统。

### 1.3 一句话介绍

基于真实用户反馈数据，使用 LangGraph + MCP 构建 AI 产品调研 Agent 工作流，帮助产品团队从用户问题中发现机会点、生成 PRD、评估 AI 输出质量，并通过 BI 看板完成产品复盘。

## 2. 项目背景

AI 产品经理在实际工作中需要持续跟踪用户反馈、GitHub Issues、社区讨论、竞品动态和产品数据。但这些信息通常分散在多个平台中，人工整理成本高，且难以形成稳定的产品决策链路。

通用大模型虽然可以辅助生成总结和 PRD，但存在以下问题：

- 缺少真实数据支撑
- 输出结果不稳定
- 容易产生幻觉
- 缺少证据引用
- 无法持续评估 AI 输出质量
- 无法和 BI 指标体系结合
- 缺少完整的产品工作流闭环

因此，本项目希望通过真实数据、Agent 工作流、工具调用、评估机制和 BI 看板，构建一个更接近真实 AI 产品经理工作场景的系统。

## 3. 目标用户

### 3.1 AI 产品经理

需要分析用户反馈、竞品功能、AI 输出效果、并形成可执行的产品需求。

### 3.2 数据产品经理
需要设计指标体系、数据模型和 BI 看板，用数据支持产品决策。

### 3.3 产品运营

需要从用户评论和反馈中发现高频问题、运营机会和用户满意度变化。

### 3.4 初级产品经理 / 产品实习生

需要通过结构化工作流学习如何做调研、分析需求、写 PRD 和评估产品效果。

## 4. 核心问题

本项目主要解决以下问题：

1. 用户反馈分散，人工整理效率低。
2. AI 生成内容缺少真实证据支撑。
3. 产品调研结果难以沉淀为结构化数据。
4. 需求优先级判断过于主观。
5. PRD 生成后缺少质量评估。
6. AI 输出缺少幻觉风险控制。
7. 产品调研与 BI 复盘之间缺少闭环。


## 5. 产品目标

本项目目标是构建一个完整的 AI 产品调研与决策平台，帮助团队完成：

- 真实用户反馈采集
- 用户痛点与需求识别
- 竞品功能矩阵分析
- 产品机会评分
- PRD 草稿生成
- AI 输出质量评估
- BI Dashboard 复盘
- 作品集级项目展示

## 6. MVP 范围

- GitHub Issues / Comments 数据采集
- 原始反馈数据清洗
- 统一 Product Research Schema

- 高频主题与痛点提取
- 机会点评分

## 7. 核心业务流程

```text
创建调研项目
→ 选择 GitHub 仓库
→ 采集 Issues / Comments
→ 清洗并入库
→ 分析主题、情绪、痛点
→ 结合竞品信息识别机会点
→ 对机会点进行优先级评分
→ 选择机会点生成 PRD
→ Evaluation Agent 检查输出质量
→ BI Dashboard 展示指标
→ 导出 PRD / 调研报告 / Case Study
```

## 8. 核心功能模块

### 8.1 数据采集模块

从 GitHub Issues、Comments、Labels、Releases 中采集真实用户反馈数据。

### 8.2 数据清洗模块

清洗 Markdown、代码块、链接、重复内容，并识别反馈类型和语言。

### 8.3 用户反馈分析模块

识别反馈主题、情绪、严重程度、用户痛点和潜在需求。

### 8.4 竞品分析模块

整理竞品功能、优势、弱点和差异化机会。

### 8.5 机会点评分模块

根据用户价值、商业价值、频率、严重程度、实现成本、风险和证据强度对机会点排序。

### 8.6 PRD 生成模块

基于选定机会点生成结构化 PRD，包括背景、用户故事、功能需求、验收标准、指标和风险。

### 8.7 AI Evaluation 模块

评估 AI 输出的相关性、准确性、可执行性、证据覆盖率和幻觉风险。

### 8.8 BI Dashboard 模块

展示反馈趋势、主题分布、机会点状态、PRD 质量、AI 评估结果和产品复盘建议。

## 9. 成功指标

- 采集 3-5 个 GitHub 仓库的真实 Issues / Comments
- MVP 阶段完成 300-1000 条反馈处理
- 作品集阶段扩展到 10000+ 条反馈
- BI 指标数量达到 20+
- PRD 完整度评分达到 4/5 以上
- AI 输出相关性评分达到 4/5 以上
- 证据覆盖率达到 80% 以上
- 低幻觉风险输出占比达到 85% 以上
- 人工修改率控制在 30% 以下
